This repo is an extension of my LaunchCode Group Capstone Project, Media Wrangler. After project submission, I forked the repo and started to work towards improving some of the applications original features. 

So far, I worked on the community aspect of the application -- improving how users comment/respond to other's movie reviews. In the original app, all comments for a movie review were on a single thread, and now, there is a tier system for user comments and how they can respond to one another. 

As a group, we discussed many ways in which to improve Media Wrangler as a whole -- adjusting features that already exsist, creating new features and cleaning/mainstreaming some of the code. 

For example...
-> the moview review form was created through bulma, and with all the moving pieces, we tossed around the idea of using Formik for validation and submission. 
-> adding a social feature that allows users to have follow friends
-> implement local showtimes and ticket booking
-> include TV shows with episode progress feature
